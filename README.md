# Your Name — Portfolio

A responsive React portfolio for a frontend developer and UI/UX designer. It is built with Vite and React, with no database or backend.

## Get started

```sh
npm install
npm run dev
```

## Personalize the portfolio

Update the editable content in `src/data/portfolio.js`:

- Replace the profile, availability, city, and email address.
- Add your real work in place of the clearly labeled concept projects.
- Update skills, work history, education, and certificates.
- Replace the sample GitHub, LinkedIn, and Dribbble profile URLs.
- Change the resume request link to your resume URL or add a PDF in `public/`.

The concept project mockups are CSS illustrations and require no image assets. Review all placeholder copy and links before publishing.

## Available scripts

- `npm run dev` — start the local development server.
- `npm run build` — create a production build in `dist/`.
- `npm run lint` — run Oxlint.
- `npm run preview` — preview the production build locally.
